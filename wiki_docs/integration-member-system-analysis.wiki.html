핵심 요약

  1. 1

    3가지 회원 타입(Web, Rewards, Unified)을 하나의 통합 인증 체계로 관리

  2. 2

    핵심 저장소는 integration / membership / cdp 3개 DB 영역이며 CRS, CMS와 실시간 동기화

  3. 3

    주요 생애주기는 로그인, 신규가입, 통합등록(Web+Rewards 병합), 전환가입, 정보수정, 비밀번호 변경, 유료 멤버십 구매, 탈퇴 처리로 구성

  4. 4

    레거시 Web 회원은 로그인 시 CDP 존재 여부에 따라 통합 가능(U) 또는 전환 대상(T)으로 판정

  5. 5

    유료 멤버십 구매 시 CMS 신규/기존 회원 연동이 분기되며, 회원 정보 수정 시 CRS/CMS 동기화가 함께 수행됨
