OPERA 예약 기준으로
포인트를 수기로 적립하거나 차감하는 절차

이 문서는 개발자용 API 명세를 PM/기획자와 운영자가 이해하기 쉽도록 재구성한 웹 매뉴얼입니다. 핵심은 먼저 OPERA 예약 정보를 조회해 resvNameId를 확인하고, 이후 수기 포인트 적립/차감 API를 호출하는 구조입니다.

문서 유형API 명세 → 운영 매뉴얼
대상 업무포인트 복구/수기 조정
핵심 API조회 1개 · 처리 1개
확인 포인트양수 적립 · 음수 차감

문서 전체 요약

개발 언어를 업무 언어로 바꿔서 먼저 이해하는 영역입니다.

한 줄 요약

고객의 OPERA 예약을 찾아서 예약 식별값인 resvNameId를 확인한 뒤, 포인트 금액을 양수면 적립, 음수면 차감으로 전송하는 수기 처리 기능입니다.

이 문서가 필요한 상황

  • 포인트가 정상 적립되지 않아 사후 복구가 필요한 경우
  • 잘못 적립된 포인트를 수기로 차감해야 하는 경우
  • OPERA 예약번호와 OMS 주문번호를 기준으로 포인트 조정 요청을 처리해야 하는 경우
  • 개발자에게 API 호출 요청을 할 때 필요한 필수값을 정리해야 하는 경우
STEP 1

예약 정보 조회

hotelCode와 pmsRsvNo로 OPERA 예약 정보를 조회합니다.

STEP 2

resvNameId 확보

조회 결과에서 수기 포인트 처리에 필요한 예약 식별값을 확인합니다.

STEP 3

포인트 적립/차감

pointAmount를 양수 또는 음수로 넣어 포인트를 조정합니다.

운영자 매뉴얼 버전

개발자가 아닌 담당자가 실제 요청·확인할 때 보는 쉬운 버전입니다.

포인트를 다시 넣어줘야 할 때

  1. 고객/예약 건을 확인합니다.
  2. 호텔 코드와 PMS 예약번호를 준비합니다.
  3. 예약 정보 조회 API로 resvNameId를 확인합니다.
  4. 적립할 포인트 금액을 pointAmount에 양수로 입력합니다. 예: 10413
  5. 처리 후 고객 포인트가 정상 증가했는지 확인합니다.

잘못 들어간 포인트를 빼야 할 때

  1. 차감 대상 예약과 포인트 금액을 확인합니다.
  2. 차감 사유와 승인 여부를 기록합니다.
  3. 예약 정보 조회 API로 resvNameId를 확인합니다.
  4. 차감할 포인트 금액을 pointAmount에 음수로 입력합니다. 예: -10413
  5. 처리 후 고객 포인트가 정상 감소했는지 확인합니다.

개발자/운영 개발자에게 전달할 요청 정보

구분전달값설명
호텔hotelCode, hostIp어느 호텔의 예약인지 확인하는 값입니다.
예약confNo, orderNo, pmsRsvNoOPERA/OMS/PMS 예약·주문 번호입니다.
식별값resvNameId예약 정보 조회 후 확보해야 하는 핵심값입니다.
포인트pointAmount적립은 양수, 차감은 음수입니다.
기준일postDate포인트 처리 기준 일자입니다.

주의사항

운영 사고를 막기 위해 꼭 확인해야 할 부분입니다.

1. 부호 실수 주의

pointAmount를 잘못 넣으면 적립해야 할 건이 차감되거나, 차감해야 할 건이 적립될 수 있습니다.

2. 예약번호 혼동 주의

confNo, orderNo, pmsRsvNo는 서로 다른 시스템 번호일 수 있으므로 요청서에 명확히 구분해야 합니다.

3. 처리 후 검수 필수

API 호출 성공 여부와 별개로 고객 포인트 내역에서 실제 반영 결과를 확인해야 합니다.

# OperaManualController API 명세

**Base URL** : `/api/ows/manual`

---

## 1. OPERA 예약 정보 조회

| 항목 | 값 |
|------|-----|
| **Method** | `GET` |
| **URL** | `/api/ows/manual/reservation-info` |
| **설명** | OPERA 예약 정보 단건 조회 (resvNameId 포함) |

### Query Parameters

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| `hotelCode` | String | 호텔 코드 (예: `JEJUA`) |
| `pmsRsvNo` | String | `parnas_rsv_pms.pms_rsv_no` 값 |

### 요청 예시

```
GET /api/ows/manual/reservation-info?hotelCode=JEJUA&pmsRsvNo=62766
```

---

## 2. 수기 포인트 적립 / 차감

| 항목 | 값 |
|------|-----|
| **Method** | `POST` |
| **URL** | `/api/ows/manual/point/posting` |
| **설명** | 수기 포인트 적립 또는 차감 / `pointAmount` 양수: 적립, 음수: 차감 |

### Request Body (`application/json`)

| 필드 | 타입 | 설명 |
|------|------|------|
| `hotelCode` | String | `parnas_hotel.hotel_code` |
| `hostIp` | String | `parnas_hotel.host_ip` |
| `postDate` | String | Posting 기준 일자 (차감인 경우 차감을 실행하는 날짜) (`yyyy-MM-dd`) |
| `pointAmount` | Integer | 포인트 금액 (차감 시 음수) |
| `confNo` | String | OPERA 예약번호 (Conf. No) / `parnas_rsv.oms_rsv_no` |
| `orderNo` | String | 주문번호 (OMS) / `parnas_rsv_pms.pms_rsv_no` |
| `resvNameId` | Long | OPERA RESV_NAME_ID → `GET /api/ows/manual/reservation-info` 응답의 `resvNameId` 값 |

### 요청 예시

```json
{
  "hotelCode":   "JEJUA",
  "hostIp":      "10.152.10.85",
  "postDate":    "2024-04-10",
  "pointAmount": 10413,
  "confNo":      "62766",
  "orderNo":     "2402245931",
  "resvNameId":  43608
}
```
